# NestJS Cheatsheet

A reference for developers moving from "hello world" to intermediate NestJS. Targets current Nest, ESM and Vitest.

| File | What it is |
| --- | --- |
| [nestjs-cheatsheet.html](nestjs-cheatsheet.html) | Full cheatsheet: request pipeline, DI, validation, guards, config, data, testing, built-in packages, good practice, common errors. Has a filter box and copy buttons. |
| [nestjs-quick-cheatsheet.html](nestjs-quick-cheatsheet.html) | Quick sheet that prints on 2 A4 pages. |

The two pages link to each other, so keep them in the same folder.

## Viewing

GitHub shows `.html` files as source. Either clone the repo and open the files in a browser, or turn on GitHub Pages for this repo (Settings, Pages, deploy from `main`).

Fonts load from Google Fonts. Offline, the pages fall back to system fonts.
